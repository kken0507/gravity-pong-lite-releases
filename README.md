# Gravity Pong ライト版(成果物の配布)

Bevy / wgpu を使わず、CPU バッファ(ネイティブ)と Canvas2D(ブラウザ)で描く、**メモリの軽い Gravity Pong**。重力体がボールを曲げる Pong です。

**このリポジトリは、成果物(実行ファイル・ブラウザ版)の配布用です。ソースコードは含まれません。**

## 遊ぶ
- **ブラウザ**: https://kken0507.github.io/gravity-pong-lite-releases/ (PC・スマホ。音は、最初の入力のあとに有効になります)
- **Linux / Windows**: [Releases](../../releases) から、実行ファイルをダウンロード(`SHA256SUMS` で照合できます)
- **Android**: [Releases](../../releases) の APK(`gravity-pong-lite-android-<版>.apk`、arm64)を端末に入れます。Google Play には出していないので、「提供元不明のアプリのインストール」の許可が要ります。更新は、新しい APK を上から入れるだけです(署名が同じなので、設定は残ります)。ゲームパッド(Bluetooth・内蔵)・タッチ・戻るボタンに対応。図形は GPU で描きます(使えない端末では、自動で CPU の描画に切り替わります)

## 操作
- **初めての方は HOW TO PLAY**(READY・ポーズ・設定画面のボタン、または H キー・パッドの Y)。画面の案内は、使っている入力(キー・タッチ・パッド)に合わせて変わります
- **P1**: W/S 移動、D スマッシュ(押して溜めたまま打ち返すと強打)、A パルス(CPU 戦では矢印キーも使えます)。**P2**: ↑↓ 移動、← スマッシュ、→ パルス
- **Space** 開始 / ポーズ、**Esc** または Tab で設定(画面のボタンも、キーだけで操作できます)、F11 全画面
- **マウス**: ホイールで上下、左ボタン長押しでスマッシュ、右クリックでパルス
- **ゲームパッド**: スティック・十字キーで移動、A スマッシュ、B パルス、Start ポーズ、Select 設定、Y で HOW TO PLAY。2 台目は P2
- **タッチ**: 左半分をドラッグして移動、右半分の上 = PULSE・下 = SMASH。画面下の中央の PAUSE でポーズ
- ネイティブ版は、画面の QUIT ボタンで終了します

## 性能(最低環境の予算内)
内部解像度 626×360 を整数倍に拡大。メモリ(RSS)12〜17 MB、実行ファイル 2.0 MB(Windows 1.3 MB)、ブラウザ版 0.15 MB。

## 既知の制限
- **Windows は、Wine での確認のみ**です(実機の Windows での音・入力・FPS・メモリは未確認)。
- 窓表示のとき、環境によって、フレーム間隔がわずかに揺れることがあります(平均 59.8 FPS)。
- 垂直同期は取っていません(合成のない素の X11 でティアリングの恐れ)。
- スマホのブラウザのタッチは、iOS Safari で確認しています。Android のブラウザは、ゲームパッドで確認しています(Brave・Chrome)。
- Android 版の確認は、Qualcomm(Adreno)の 2 機種(Galaxy Note 8・Retroid Pocket 5)です。ほかの GPU の機種は未確認です。
